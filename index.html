Standalone sideloading for Meta Quest.

Squire VR is a native Android client built to interface directly with VRP mirrors. Download, extract, and deploy APK/OBB packages directly on your headset without a PC or mobile bridge.

Core Capabilities

01

Autonomous Execution

Runs natively on Quest hardware with zero external PC or phone dependencies required.

02

Smart-Resume Streams

Built-in fault tolerance automatically recovers interrupted downloads without data loss.

03

Automated Deployment

Handles APK installation and OBB directory routing in a single background pass.

04

Real-Time Mirror Sync

Compares installed package versions against remote mirrors to flag pending updates.

05

SQL Metadata Engine

High-concurrency local SQLite caching for instant catalog filtering and search.

06

Pre-Flight Validation

Verifies available storage thresholds and archive integrity prior to extraction.

Diagnostics & Notices

ERR: NULL_POINTER_ERROR
Verify that "All Files Access" permission is granted in Android settings and that your configured mirror servers are reachable.
ERR: STORAGE_EXHAUSTION
Extraction requires temporary headroom. Ensure your free internal storage is at least 2x the target package size before starting a download.
